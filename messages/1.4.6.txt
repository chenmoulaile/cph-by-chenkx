cph-by-chenkx 1.4.6
===================

Fixed:

* Adding a test from the clipboard (or exporting) inside the run panel left the
  cards stale until the next run.
* Re-sending the same sample from the browser could overwrite an answer you had
  accepted by hand; conflicting answers are now kept and reported.
* Pasting input after the program exited no longer throws or repeats the status
  message.
* A typo in a command placeholder is now listed in the compile panel instead of
  only appearing in the console.

New:

* `regard_pe_as_ac` setting: pass "presentation error" as accepted, for online
  judges that count it as correct (default stays strict).
* Doctor now checks command placeholders and prints a copy-pasteable Markdown
  report (Sublime build, platform, Python, per-language commands).
* `Ctrl+Alt+M` (Cmd+Alt+M on macOS): pick a test and run / show detail / edit it
  without touching the mouse.
* One shared merge policy for tests coming from files, the clipboard, the
  browser and stress-test counterexamples: deduplicated by input, answers are
  only filled in, never overwritten.
